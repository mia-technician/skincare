⚠️ 内源性老化

由基因、端粒损耗、激素衰退、细胞自噬能力下降驱动，皮肤缓慢程序性衰老。表皮老化、真皮老化、附属器老化，还有全身激素带来的系统性影响。
表皮老化：
1️⃣基底层干细胞池衰减:分裂能力下降，表皮更新周期拉长：年轻人≈28 天，自然老化的老人可拉长至 40–60 天。👉 后果：角质不平均、屏障变薄、锁水能力下降，干痒
2️⃣细胞自噬、线粒体自噬衰退：受损线粒体、氧化蛋白碎片、脂褐素清除变慢 → 脂褐素在胞内堆积 → 淡黄至深褐色的老年斑（不是日晒黑斑）
3️⃣表皮细胞DNA修复能力逐年减弱：损伤监控通路活性下降，小损伤累积。如果没有UVB的强打击，DNA突变速度慢很多，皮肤癌风险很低
4️⃣表皮变薄（生理性）：朗格汉斯细胞数量变少 → 皮肤局部免疫力下降，抵御病毒、真菌能力变弱
5️⃣黑素细胞逐年减少、分布不均：易出现老年性白点病（纯自然老化，不是晒斑）
6️⃣局部黑素细胞异常增殖 → 良性的老年斑（脂溢性角化，内源性也会长，日晒会大幅加速）
真皮老化：纯内源真皮老化，弹性纤维大多完好，光老化才造成弹性纤维大量断裂碎片化
1️⃣成纤维细胞活力下降、真皮干细胞储备衰减：新生胶原合成速率降低，Ⅰ 型、Ⅲ 型胶原缓慢减少，胶原纤维变细，排列疏松。👉 自然老化：胶原整体变少；光老化：胶原被MMP大量降解、弹性纤维碎成一堆发色团碎片
2️⃣玻尿酸含量逐年下降 → 真皮保水能力下降 → 皮肤慢慢边干瘪
3️⃣血管退化（生理性）：真皮毛细血管网密度缓慢降低，血管壁变薄 → 供血变少，皮肤苍白、缺少气色。不像光老化那样大量红血丝扩张
4️⃣衰老细胞SASP缓慢累积：成纤维细胞端粒耗尽变成衰老细胞 → 持续低水平分泌SASP → 慢性无菌性炎症/炎性衰老（内源性老化的核心动力）→ SASP抑制周边干细胞活性 → 老化加速⏩
5️⃣金属蛋白酶MMP上调，降解胶原。但不像UVA带来的那种MMP爆发式升高
皮肤附属器的老化：
1️⃣毛囊：毛囊干细胞衰退 → 毛发变细、脱发。黑素干细胞耗竭，头发变白
2️⃣皮脂腺：皮脂腺分泌大多是下降（更年期之后很明显），皮肤越来越干，少数区域代偿出油
3️⃣汗腺：小汗腺数量、功能衰退 → 出汗变少，体温调节能力变差
雌激素快速下降，是皮肤自然老化重要的推手 → 女性围绝经期非常明显

内源性老化的氧化压力（⚠️无关日晒）
1️⃣线粒体有氧代谢持续产出ROS → ROS攻击干细胞DNA端粒 → 干细胞老化加速⏩ → 同时，随着老化，细胞垃圾的清除能力日渐减弱 → 氧化压力日渐升高
2️⃣胞内慢慢堆积氧化蛋白、氧化脂质碎片、脂褐素（胞内发色团）。这些感光碎片如果没有UVA照射，就不会启动自由基爆发的光老化恶性循环
